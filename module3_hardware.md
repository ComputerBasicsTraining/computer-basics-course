# Module 3 – Computer Hardware

## What is Hardware?

Hardware is the **physical** parts of a computer — the components you can touch.

Examples:
- CPU
- RAM
- Motherboard
- Storage (SSD/HDD)
- Power Supply
- Graphics Card
- Case
- Cooling Fans

## Main Hardware Components

### 1. Motherboard
- The main circuit board
- Connects all components together
- Allows communication between CPU, RAM, storage, and devices

### 2. CPU (Processor)
- The “brain” of the computer
- Executes instructions
- Measured in GHz and cores

### 3. RAM (Memory)
- Temporary working memory
- Stores active programs
- More RAM = smoother multitasking

### 4. Storage
- SSD: fast, silent, modern
- HDD: slower, mechanical
- Stores files, apps, and the operating system

### 5. GPU (Graphics Card)
- Handles graphics and video
- Important for gaming, video editing, 3D work

### 6. Power Supply (PSU)
- Provides electricity to all components
- Measured in watts (W)

### 7. Cooling System
- Fans or liquid cooling
- Keeps the computer from overheating

## Why Hardware Matters
Better hardware means:
- Faster performance
- Better multitasking
- Smoother gaming
- More reliability
- Longer lifespan
