# Module 4 – Software

## What is Software?

Software is the **programs and applications** that run on your computer.  
It tells the hardware what to do.

Examples:
- Web browsers
- Games
- Word processors
- Media players
- Operating systems

## Types of Software

### 1. System Software
This controls the computer itself.
Examples:
- Windows
- macOS
- Linux

### 2. Application Software
These are programs you use to do tasks.
Examples:
- Chrome
- Word
- Photoshop
- Spotify

### 3. Utility Software
Helps maintain and optimize the computer.
Examples:
- Antivirus
- Disk cleanup tools
- Backup tools

## How Software Works
Software sends instructions to the CPU.  
The CPU processes them.  
RAM stores the active program.  
Storage keeps the software installed.

## Why Software Matters
Without software:
- You cannot browse the internet
- You cannot play games
- You cannot write documents
- You cannot use the computer at all
