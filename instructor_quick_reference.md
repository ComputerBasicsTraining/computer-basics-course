Timing Guide
Modules: 20–40 minutes each

Module Tests: 5–10 minutes

Final Exam: 20–30 minutes

Total Course Duration: ~6–8 hours

Key Teaching Points (Per Module)
Module 1 — Basics
CPU, RAM, storage, I/O devices

Use analogies (CPU = brain)

Module 2 — Operating Systems
File systems, navigation, system tools

Demonstrate real OS actions

Module 3 — Hardware
Motherboard, CPU, RAM, GPU, PSU

Show diagrams or real components

Module 4 — Software
System software vs applications

Utilities and updates

Module 5 — Networks
LAN/WAN, routers, modems, IP

Packets = envelopes analogy

Module 6 — Internet
DNS, IP, servers, clients

HTTPS indicators

Module 7 — Security
Malware, phishing, passwords

Show real phishing examples

Module 8 — Maintenance
Cleaning, optimization, updates

Safe physical cleaning

Module 9 — Troubleshooting
Step‑by‑step diagnosis

“Restart first” rule

Module 10 — Digital Citizenship
Privacy, safety, communication

Responsible online behavior

Confusing RAM vs storage
