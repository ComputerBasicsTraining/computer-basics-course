# Module 8 – Computer Maintenance

## What is Computer Maintenance?

Computer maintenance is the process of keeping your computer:
- Fast
- Clean
- Secure
- Reliable

Good maintenance prevents problems before they happen.

## Types of Maintenance

### 1. Physical Cleaning
- Remove dust from fans
- Clean keyboard and mouse
- Keep vents clear
- Prevent overheating

### 2. Software Cleaning
- Delete unused files
- Remove old programs
- Clear temporary files
- Empty recycle bin

### 3. Performance Optimization
- Update drivers
- Manage startup programs
- Defragment HDD (not needed for SSD)
- Keep OS updated

### 4. Security Maintenance
- Update antivirus
- Scan for threats
- Install security patches
- Use strong passwords

## Signs Your Computer Needs Maintenance
- Slow performance
- Overheating
- Loud fans
- Programs freezing
- Low storage space

## Benefits of Maintenance
- Faster computer
- Longer lifespan
- Fewer crashes
- Better security
- Smoother performance
