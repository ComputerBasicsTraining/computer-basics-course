Trainer’s Guide – Computer Fundamentals Course
Purpose of This Guide
This guide supports instructors delivering the Computer Fundamentals Course.
It provides teaching strategies, timing recommendations, common student challenges, and practical activities for each module.

Use this guide alongside the module files, tests, final exam, scoring sheet, and progress tracker.

📘 Teaching Structure Overview
Recommended Delivery Format
10 modules

10 module tests

1 final exam

Hands‑on practice after each module

Progress tracking using the provided tracker

Certificate issued upon completion

Suggested Timing
Each module: 20–40 minutes

Module tests: 5–10 minutes

Final exam: 20–30 minutes

Total course duration: ~6–8 hours

📚 Module‑by‑Module Teaching Guidance
Module 1 — Computer Basics
Teaching Focus
Explain CPU, RAM, storage, input/output devices.

Use real‑world analogies (CPU = brain, RAM = short‑term memory).

Common Student Challenges
Confusing RAM with storage

Not understanding “processing”

Instructor Tips
Show physical components if possible

Use diagrams or simple sketches

Practical Activity
Identify components on a real computer or image.

Module 2 — Operating Systems
Teaching Focus
What an OS does

Differences between Windows, macOS, Linux

Common Challenges
Understanding file systems

Confusing apps with system software

Instructor Tips
Demonstrate navigating folders

Show Task Manager / Activity Monitor

Practical Activity
Students locate files, rename them, and move them.

Module 3 — Computer Hardware
Teaching Focus
Motherboard, CPU, RAM, GPU, PSU, cooling

Common Challenges
Understanding how components connect

Misunderstanding GPU vs CPU roles

Instructor Tips
Use motherboard diagrams

Explain airflow and cooling simply

Practical Activity
Label hardware components on a diagram.

Module 4 — Software
Teaching Focus
System software vs applications

Utilities and updates

Common Challenges
Thinking “software = apps only”

Instructor Tips
Show examples of utilities (Disk Cleanup, Task Manager)

Practical Activity
Students list 5 apps and classify them.

Module 5 — Computer Networks
Teaching Focus
LAN, WAN, Wi‑Fi, routers, modems, IP addresses

Common Challenges
Confusing router vs modem

Understanding packets

Instructor Tips
Use simple analogies (packets = envelopes)

Practical Activity
Students draw a home network diagram.

Module 6 — The Internet
Teaching Focus
DNS, IP, servers, clients, HTTP/HTTPS

Common Challenges
Understanding DNS

Thinking “internet = Wi‑Fi”

Instructor Tips
Explain DNS like a phonebook

Show how HTTPS appears in browsers

Practical Activity
Students look up a domain’s IP using an online tool.

Module 7 — Computer Security
Teaching Focus
Malware, phishing, passwords, antivirus

Common Challenges
Recognizing phishing

Creating strong passwords

Instructor Tips
Show real phishing examples

Teach password patterns (not specific passwords)

Practical Activity
Students identify safe vs unsafe emails.

Module 8 — Computer Maintenance
Teaching Focus
Cleaning, optimization, updates

Common Challenges
Thinking updates “break things”

Not cleaning devices physically

Instructor Tips
Explain why updates matter

Demonstrate safe cleaning methods

Practical Activity
Students perform a mock maintenance checklist.

Module 9 — Troubleshooting
Teaching Focus
Step‑by‑step problem solving

Restarting, checking cables, checking settings

Common Challenges
Jumping to conclusions

Overlooking simple fixes

Instructor Tips
Teach “Restart first”

Use real troubleshooting scenarios

Practical Activity
Students diagnose a simulated issue.

Module 10 — Digital Citizenship
Teaching Focus
Online safety, privacy, communication, ethics

Common Challenges
Oversharing online

Weak privacy settings

Instructor Tips
Show privacy settings on real platforms

Discuss respectful communication

Practical Activity
Students adjust privacy settings on a mock profile.

📝 Assessment Guidance
Module Tests
Use tests to confirm understanding before moving on.

Encourage students to review incorrect answers.

Final Exam
40 questions covering all modules

Passing score recommended: 70% or higher

Scoring Sheet
Record results clearly

Add instructor comments for improvement

Certificate
Issue only after:

All modules completed

All tests completed

Final exam passed
