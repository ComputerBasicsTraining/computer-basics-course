# INSTRUCTOR QUICK‑REFERENCE SHEET
## Computer Fundamentals Course

----------------------------------------

## Course Flow
1. Module 1 – Computer Basics
2. Module 2 – Operating Systems
3. Module 3 – Computer Hardware
4. Module 4 – Software
5. Module 5 – Computer Networks
6. Module 6 – The Internet
7. Module 7 – Computer Security
8. Module 8 – Computer Maintenance
9. Module 9 – Troubleshooting
10. Module 10 – Digital Citizenship
11. Final Exam
12. Certificate Issued

----------------------------------------

## Timing Guide
Modules: 20–40 minutes  
Module Tests: 5–10 minutes  
Final Exam: 20–30 minutes  
Total Duration: ~6–8 hours  

----------------------------------------

## Key Teaching Points

### Module 1 – Basics
CPU, RAM, storage, I/O devices

### Module 2 – Operating Systems
File systems, navigation, system tools

### Module 3 – Hardware
Motherboard, CPU, RAM, GPU, PSU

### Module 4 – Software
System software vs applications

### Module 5 – Networks
LAN/WAN, routers, modems, IP

### Module 6 – Internet
DNS, IP, servers, clients

### Module 7 – Security
Malware, phishing, passwords

### Module 8 – Maintenance
Cleaning, optimization, updates

### Module 9 – Troubleshooting
Step‑by‑step diagnosis

### Module 10 – Digital Citizenship
Privacy, safety, communication

----------------------------------------

## Common Student Challenges
Confusing RAM vs storage  
Misunderstanding OS vs apps  
Router vs modem confusion  
Oversharing online  
Skipping basic troubleshooting steps  

----------------------------------------

## Assessment Flow
Teach module  
Give module test  
Review incorrect answers  
Continue to next module  
After Module 10 → Final Exam  
Use scoring sheet  
Update progress tracker  
Issue certificate

Use real examples  
Encourage questions  
Reinforce safe digital habits
