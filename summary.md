Computer Fundamentals Course – Summary Page
Course Overview
The Computer Fundamentals Course provides a complete introduction to essential computer knowledge and digital skills.
It is designed for beginners, students, and anyone wanting a strong foundation in modern computing.

The course contains 10 modules, each with a dedicated test, plus a Final Exam, Answer Key, Scoring Sheet, and Certificate of Completion.

📘 Module Summaries
Module 1 — Computer Basics
Covers the core components of a computer: CPU, RAM, storage, input/output devices, and how they work together.

Module 2 — Operating Systems
Explains Windows, macOS, Linux, system functions, file management, and how the OS controls hardware and software.

Module 3 — Computer Hardware
Breaks down internal components: motherboard, CPU, RAM, GPU, PSU, cooling systems, and how hardware affects performance.

Module 4 — Software
Covers system software, applications, utilities, updates, and how software interacts with hardware.

Module 5 — Computer Networks
Introduces LAN, WAN, Wi‑Fi, routers, modems, IP addresses, packets, and how devices communicate.

Module 6 — The Internet
Explains servers, clients, DNS, IP, HTTP/HTTPS, websites, and how global networks operate.

Module 7 — Computer Security
Covers malware, phishing, strong passwords, antivirus tools, updates, and safe browsing practices.

Module 8 — Computer Maintenance
Teaches cleaning, optimization, updates, security maintenance, and how to keep a computer running smoothly.

Module 9 — Troubleshooting
Provides step‑by‑step methods for diagnosing and fixing common computer problems.

Module 10 — Digital Citizenship
Covers online safety, privacy, respectful communication, digital footprints, and responsible technology use.

📝 Assessments Included

Complete answer key

🎓 Learning Outcomes
By completing this course, students will be able to:

Identify computer components and their functions

Use operating systems effectively

Understand hardware and software interactions

Navigate networks and the internet

Practice safe and responsible digital behavior

Maintain and troubleshoot computers

Demonstrate competency through assessments
