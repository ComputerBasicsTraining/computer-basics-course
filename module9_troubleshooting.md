# Module 9 – Troubleshooting

## What is Troubleshooting?

Troubleshooting is the process of finding and fixing computer problems.  
It helps you solve issues quickly and keep your system running smoothly.

## Common Computer Problems

### 1. Slow Performance
- Too many programs running
- Low RAM
- Old hardware
- Malware

### 2. No Internet
- Router issues
- Wi‑Fi disconnected
- Incorrect settings
- Service outage

### 3. Computer Freezing
- Overheating
- Faulty software
- Driver problems

### 4. No Sound
- Muted speakers
- Wrong audio device selected
- Driver issues

### 5. Screen Problems
- Loose cables
- Wrong resolution
- GPU issues

## Basic Troubleshooting Steps

### Step 1: Restart the Computer
- Fixes many temporary issues

### Step 2: Check Cables and Connections
- Ensure everything is plugged in

### Step 3: Check Settings
- Audio, display, network settings

### Step 4: Update Software
- Drivers, OS, apps

### Step 5: Scan for Malware
- Use antivirus tools

### Step 6: Check Hardware
- Fans, cables, overheating

## When to Get Help
- Hardware failure  
- Blue screen errors  
- Repeated crashes  
- Burning smell  
- Data loss
