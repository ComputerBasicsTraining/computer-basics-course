# Module 7 – Computer Security

## What is Computer Security?

Computer security protects your:
- Data
- Devices
- Accounts
- Privacy

It prevents hackers, viruses, and unauthorized access.

## Common Security Threats

### 1. Viruses
- Malicious programs
- Can delete files or damage systems

### 2. Malware
- Any harmful software
- Includes spyware, ransomware, trojans

### 3. Phishing
- Fake emails or messages
- Trick you into giving passwords or personal info

### 4. Hackers
- People who try to break into systems

### 5. Weak Passwords
- Easy to guess
- Make accounts vulnerable

## How to Stay Safe

### Strong Passwords
- Use long passwords
- Mix letters, numbers, symbols

### Two‑Factor Authentication (2FA)
- Adds an extra security step
- Example: SMS code or authenticator app

### Antivirus Software
- Scans for threats
- Removes harmful files

### Software Updates
- Fix security holes
- Keep your system safe

### Safe Browsing
- Avoid suspicious links
- Don’t download unknown files

## Why Security Matters
Good security protects:
- Your identity  
- Your money  
- Your files  
- Your privacy  
- Your computer
