# Module 6 – The Internet

## What is the Internet?

The **internet** is a global network of millions of computers connected together.  
It allows people to share information, communicate, and access services worldwide.

## How the Internet Works

### 1. Servers
- Powerful computers that store websites, apps, and data

### 2. Clients
- Your computer, phone, or tablet
- Requests information from servers

### 3. IP Addresses
- Every device has a unique number
- Helps identify where data should go

### 4. DNS (Domain Name System)
- Converts website names into IP addresses
- Example: `google.com` → IP address

### 5. HTTP / HTTPS
- Rules for how data is sent between your device and websites
- HTTPS is secure and encrypted

## Internet Services

### Web Browsing
- Chrome, Edge, Firefox

### Email
- Gmail, Outlook

### Social Media
- Facebook, Instagram, TikTok

### Streaming
- Netflix, YouTube, Spotify

### Cloud Storage
- OneDrive, Google Drive, Dropbox

## Safety on the Internet

- Use strong passwords  
- Avoid suspicious links  
- Keep software updated  
- Use antivirus  
- Don’t share personal info
