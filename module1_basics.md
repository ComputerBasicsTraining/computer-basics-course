# Module 1 – Computer Basics

## Lesson 1 – The Four Main Parts of a Computer

### 1. CPU – The Brain
- Executes instructions
- Handles all processing
- Faster CPU = faster computer

### 2. RAM – Short-Term Memory
- Holds programs currently running
- Clears when power is off
- More RAM = more multitasking

### 3. Storage – Long-Term Memory
- SSD (fast), HDD (slow)
- Stores files, programs, Windows
- Does not clear when power is off

### 4. Input / Output
- Input: keyboard, mouse, touchscreen
- Output: monitor, speakers, printer
