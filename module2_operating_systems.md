# Module 2 – Operating Systems

## What is an Operating System?

An **Operating System (OS)** is the main software that manages your computer.  
It controls the hardware, runs programs, and provides the interface you use every day.

Examples:
- Windows
- macOS
- Linux
- Android
- iOS

## What the OS Does

### 1. Manages Hardware
- Keyboard
- Mouse
- CPU
- RAM
- Storage
- Screen

### 2. Runs Programs
- Apps
- Games
- Tools
- Browsers

### 3. Provides the User Interface
- Desktop
- Start Menu
- Taskbar
- Windows and icons

### 4. Handles Files
- Creating files
- Saving files
- Moving files
- Deleting files

## Why Operating Systems Matter
Without an OS, your computer cannot:
- Start
- Run apps
- Display anything
- Use hardware
